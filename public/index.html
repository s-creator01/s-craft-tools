    Help translate S-Craft Tools

    Thank you for helping make S-Craft Tools easier to use in more languages.

    Not open yet: English is currently the only language. The public repository and translation files are still being prepared.

    How contributing will work

    1. Once the repository is public, choose a language you know well and check whether a translation is already in progress.
    2. Follow the translation guide in the repository to suggest a new translation or improve an existing one. You can also report an unclear phrase.
    3. A reviewer will check the suggestions before they appear in the app.

    Translate the meaning clearly, keep placeholders and formatting unchanged, and never include personal files or sensitive information in a contribution.

    We will add the repository link and detailed instructions here when contributions are ready.
