# Contributing to S-Craft Tools

Thanks for helping improve S-Craft Tools! You can report a bug, suggest a feature, help translate the interface, or submit a pull request.

## Report a bug

Search [GitHub Issues](https://github.com/s-creator01/s-craft-tools/issues) to see if someone has already reported the problem. If you find an existing report, add any details that could help reproduce it. Otherwise, sign in to GitHub and click **New issue**.

Include:

- The tool you were using
- What you expected and what happened
- The steps to reproduce the problem
- Your browser, operating system, and device

## Suggest a feature

Open an issue on the [Issues page](https://github.com/s-creator01/s-craft-tools/issues). Tell us what you’d like to add or change, which tool it relates to, and how it would help you.

For larger changes, please open an issue before writing code so we can discuss the idea together.

## Help translate

English is currently the only interface language. You can suggest translations while we work on support for more languages.

Search [existing issues](https://github.com/s-creator01/s-craft-tools/issues), then open an issue titled **Translation — [language]**. Include the language and locale, the original English text, your translation, and where the text appears. Please keep placeholders, filenames, keyboard shortcuts, and technical units unchanged.

If you submit a translation pull request, link the issue and mention which screens you checked.

## Submit a pull request

Describe what changed, link any related issue, and explain how you tested it. Please preserve existing behavior outside your change and keep third-party license notices intact.

## Protect your privacy

Issues and pull requests are public. Leave out personal details, passwords, API keys, and private files. If a sample helps explain a problem, use a small file made for testing.
