# Contribute to S-Craft Tools

## Help translate

Once the repository is public, open a GitHub issue titled **Translation — [language]**. Include the language and locale, the English text, your proposed translation, and where it appears in the app. Search existing issues first so translators can work together.

If you prefer a pull request, link the translation issue and explain which screens you checked. Keep placeholders, filenames, keyboard shortcuts and technical units intact. Check long labels on a narrow screen. Use sample files when showing a translation in context.

English is the current interface language. Translation contributions can be collected while additional language support is developed.

## Report a bug

Once the repository is public, search the existing [issues](https://github.com/s-creator01/s-craft-tools/issues) before opening a new one. Include the tool, operating system and browser, steps to reproduce, expected and actual results, and a small non-sensitive sample if useful. Do not attach private files or credentials.

## Suggest an improvement

Open an issue describing the problem and the improvement you propose. If you submit a pull request, link the issue, describe the change and explain how you tested it. Preserve existing behavior and third-party license notices.
